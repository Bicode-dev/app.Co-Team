Questions fréquentes

Est-ce légal ?▼
Co-Chan télécharge uniquement des fichiers déjà publics. L'usage reste sous votre responsabilité.
Windows Defender bloque le fichier ?▼
Co-Chan ne devrait jamais déclencher Windows Defender. Cependant, si une alerte apparaît sur votre machine, ne lancez pas le fichier et signalez-le nous immédiatement sur le Discord — nous investiguerons au plus vite.
Version Android disponible ?▼
Oui ! Script d'installation Termux dans le dépôt GitHub.
Quels serveurs sont utilisés ?▼
Co-Chan supporte trois serveurs : Sibnet, Vidmoly et Sendvid. Le meilleur serveur disponible est sélectionné automatiquement pour garantir la meilleure vitesse.
