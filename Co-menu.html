FAQ

Questions fréquentes

À quoi sert Co-Menu par rapport aux autres scripts ? ▼
Co-Menu est un lanceur centralisé. Au lieu de garder plusieurs fichiers .exe séparés, vous n'avez qu'un seul fichier. Co-Menu télécharge et lance automatiquement Co-Flix, Co-Chan et Co-Tube selon votre choix.
Windows Defender bloque le fichier ? ▼
Co-Menu ne devrait jamais déclencher Windows Defender. Si une alerte apparaît, ne lancez pas le fichier et signalez-le immédiatement sur le Discord.
Faut-il avoir les autres outils déjà installés ? ▼
Non. Co-Menu télécharge automatiquement les scripts manquants depuis GitHub au premier lancement. Tout est géré pour vous.
Version Android disponible ? ▼
Oui ! Co-Menu fonctionne dans Termux sur Android. L'interface bascule automatiquement sur un menu numéroté adapté à la saisie mobile. Script disponible dans le dépôt GitHub.
Comment mettre à jour les outils ? ▼
Supprimez le dossier py/ créé à côté de Co-menu.exe, puis relancez Co-Menu. Il retéléchargera les dernières versions automatiquement.
