FAQ

Questions fréquentes

À quoi sert Co-Menu par rapport aux autres scripts ? ▼
Co-Menu est un lanceur centralisé. Au lieu de garder plusieurs .exe séparés, un seul fichier suffit. Co-Menu télécharge et lance automatiquement les outils selon votre choix.
Windows Defender bloque le fichier ? ▼
Co-Menu ne devrait jamais déclencher Windows Defender. Si une alerte apparaît, ne lancez pas le fichier et signalez-le immédiatement sur le Discord.
Faut-il avoir les autres outils déjà installés ? ▼
Non. Co-Menu télécharge automatiquement les scripts manquants depuis GitHub au premier lancement. Tout est géré pour vous.
Version Android disponible ? ▼
Oui ! Co-Menu fonctionne dans Termux sur Android. L'interface bascule sur un menu numéroté adapté. Script disponible sur GitHub.
Comment mettre à jour les outils ? ▼
Supprimez le dossier py/ créé à côté de Co-menu.exe, puis relancez. Co-Menu retélécharge les dernières versions automatiquement.
