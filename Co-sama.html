Guide

Utilisation en 4 étapes

01

Lancez Co-Sama

Double-clic sur Co-Sama.exe (Windows) ou python3 Co-sama.py dans Termux. Aucune installation préalable requise.

02

Entrez le titre ou l'URL

Saisissez le nom de la série ou collez directement l'URL d'un chapitre. Co-Sama détecte la source automatiquement.

03

Choisissez les chapitres

Téléchargez un chapitre précis, une plage 1-50, ou la série entière d'un seul coup.

04

Profitez hors-ligne

Les pages sont sauvegardées dans /Download/scans/<Titre>/Chapitre-XX/ — prêtes à lire avec n'importe quelle visionneuse.

Questions fréquentes

FAQ

Où sont sauvegardés les scans téléchargés ? ▼
Sur PC dans le dossier scans/ à côté du script. Sur Android via Termux dans /storage/emulated/0/Download/scans/ — accessible depuis votre galerie.
Puis-je télécharger plusieurs séries en même temps ? ▼
Oui, lancez plusieurs instances de Co-Sama dans des onglets Termux séparés ou dans des fenêtres différentes sur PC.
Le téléchargement s'est interrompu, dois-je tout recommencer ? ▼
Non. Co-Sama détecte automatiquement les chapitres déjà présents et reprend là où il s'est arrêté. Relancez simplement la même commande.
Co-Sama fonctionne-t-il sur Windows sans Python ? ▼
Oui, le fichier .exe disponible dans les releases GitHub est autonome — Python n'est pas requis sur Windows.
Quelle visionneuse utiliser pour lire les scans téléchargés ? ▼
Sur PC : CDisplayEx ou MComix. Sur Android : Perfect Viewer ou Tachiyomi en mode local. Les pages sont des images JPG/PNG standard compatibles avec toute visionneuse.
